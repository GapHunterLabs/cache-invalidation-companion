Reports a .save(...) call in a method that never touches the class's own hand-rolled Map-backed cache (filled with computeIfAbsent or a containsKey + put get-or-compute pattern).

After the write, the cache keeps serving the old value: what is read no longer matches what was stored.

Only a Map cache declared in the same class is checked. @Cacheable, Caffeine and Redis caches are not covered.
